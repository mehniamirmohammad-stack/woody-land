# وودی لند: راهنمای کامل

این بسته همه‌چیز را دارد: خود بازی، آیکن، نصب مثل اپ (PWA) و ساخت APK اندروید با گیت‌هاب.

## فایل‌های بسته
```
index.html                    خود بازی
manifest.webmanifest          مشخصات اپ (اسم، آیکن)
sw.js                         کش برای نصب مثل اپ
icon-192.png / icon-512.png   آیکن اپ
icon.svg                      آیکن اصلی (برداری)
assets/icon-only.png          آیکن ۱۰۲۴ برای ساخت آیکن‌های اندروید
package.json                  لیست کتابخانه‌های ساخت APK
capacitor.config.json         اسم و شناسه‌ی اپ اندروید
.github/workflows/android.yml دستور ساخت APK
.gitignore
```

## بخش ۱: ساخت مخزن و آپلود
1. در github.com وارد حسابت شو (اگر نداری، رایگان بساز).
2. بالا سمت راست «+‏» و بعد «New repository».
3. Repository name را `woody-land` بگذار، «Public» را انتخاب کن و «Create repository» بزن.
4. زیپ را از حالت فشرده دربیاور.
5. در صفحه‌ی مخزن «uploading an existing file» (یا Add file > Upload files) را بزن.
6. همه‌ی فایل‌ها و پوشه‌ها را بکش و رها کن، به‌خصوص پوشه‌ی `assets`. پوشه‌ی `.github` هم باید باشد.
7. «Commit changes» را بزن.

اگر پوشه‌ی `.github` آپلود نشد (چون مخفی است): «Add file > Create new file» را بزن، در کادر اسم تایپ کن `.github/workflows/android.yml` و محتوای فایل `android.yml` از زیپ را در کادر بزرگ پیست کن. بعد Commit بزن.

## بخش ۲: روشن کردن سایت بازی (GitHub Pages)
1. در مخزن: Settings و بعد Pages.
2. Source را «Deploy from a branch» بگذار.
3. Branch را `main` و پوشه را `/ (root)` انتخاب کن و Save بزن.
4. بعد از ۱ تا ۳ دقیقه، آدرس بازی بالای همان صفحه می‌آید:
   `https://نام‌کاربری.github.io/woody-land/`

## بخش ۳: نصب مثل اپ (PWA)، سریع‌ترین راه
- اندروید: آدرس بازی را در Chrome باز کن. منوی سه‌نقطه، بعد «Add to Home screen» یا «Install app».
- آیفون: در Safari دکمه‌ی Share، بعد «Add to Home Screen».
- آیکن وودی لند روی صفحه‌ی اصلی می‌آید و بازی تمام‌صفحه باز می‌شود.

## بخش ۴: ساخت فایل APK اندروید
1. در مخزن تب «Actions» را باز کن. اگر پیام فعال‌سازی دید، «I understand my workflows, go ahead and enable them» را بزن.
2. در ستون چپ «Build Android APK» را انتخاب کن.
3. «Run workflow» و بعد دکمه‌ی سبز «Run workflow» را بزن. (با هر Commit جدید هم خودکار اجرا می‌شود.)
4. حدود ۵ تا ۱۰ دقیقه صبر کن تا کنار اجرا تیک سبز بیاید.
5. روی اسم همان اجرا کلیک کن. پایین صفحه در Artifacts، فایل `woody-land-apk` را دانلود کن و زیپش را باز کن.
6. فایل `app-debug.apk` را به گوشی بفرست و بازش کن.
7. اندروید اجازه‌ی «نصب از منابع ناشناس» را می‌خواهد. «Settings» و بعد «Allow from this source» را روشن کن و «Install» را بزن.
8. اگر Play Protect هشدار داد، «Install anyway» را بزن.

## به‌روزرسانی بازی
1. فایل جدید `index.html` را با همان اسم آپلود کن (Add file > Upload files) و Commit بزن.
2. سایت چند دقیقه بعد به‌روز می‌شود و APK جدید هم خودکار ساخته می‌شود.
3. APK جدید را از Actions دانلود کن و روی نسخه‌ی قبلی نصب کن.

## اگر خطا داد
- **ضربدر قرمز در Actions:** روی اجرا و بعد مرحله‌ی قرمز کلیک کن، متن خطا را کپی کن و بفرست.
- **Workflow در لیست نیست:** مسیر باید دقیقاً `.github/workflows/android.yml` باشد، با نقطه‌ی اول.
- **آیکن اندروید پیش‌فرض است:** مطمئن شو `assets/icon-only.png` آپلود شده.
- **سایت ۴۰۴ داد:** چند دقیقه صبر کن. مطمئن شو فایل اسمش `index.html` است.
- **آیکن PWA عوض نشد:** اپ را از صفحه‌ی اصلی پاک کن و دوباره اضافه کن.

## نکته‌ها
- بازی برای بارگذاری Three.js و فونت‌ها اینترنت لازم دارد.
- پیشرفت بازیکن در مرورگر یا اپ خودش ذخیره می‌شود، نه روی گیت‌هاب.
- APK از نوع debug است: برای نصب شخصی خوب است، برای گوگل‌پلی باید نسخه‌ی release امضاشده ساخته شود.
- کدهای هدیه رمزشده داخل بازی هستند و فقط روی همان دستگاه یک‌بار مصرف‌اند.
- شناسه‌ی اپ `com.mrmehni.woodyland` است و در `capacitor.config.json` عوض می‌شود.
