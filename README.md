# وودی لند: ساخت اپلیکیشن

دو راه داری. راه ۱ ساده و سریع است. راه ۲ فایل APK اندروید می‌سازد.

## ساختار مخزن
```
index.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
package.json
capacitor.config.json
.github/workflows/android.yml
.gitignore
```

## راه ۱: نصب مثل اپ (PWA)، بدون ساخت فایل
1. همه‌ی فایل‌ها را در مخزن گیت‌هاب آپلود کن و GitHub Pages را روشن کن (آموزش قبلی).
2. آدرس `https://نام‌کاربری.github.io/woody-land/` را در Chrome گوشی باز کن.
3. منوی سه‌نقطه، بعد «Add to Home screen» (افزودن به صفحه اصلی) یا «Install app».
4. حالا آیکن وودی لند روی صفحه‌ی اصلی است و تمام‌صفحه و بدون نوار آدرس باز می‌شود.
در آیفون: Safari، دکمه‌ی Share، بعد «Add to Home Screen».

## راه ۲: فایل APK اندروید با GitHub Actions
گیت‌هاب خودش APK را روی سرورش می‌سازد و لازم نیست چیزی روی کامپیوتر نصب کنی.

1. همه‌ی فایل‌ها را در مخزن آپلود کن. پوشه‌ی `.github/workflows` هم باید باشد.
   نکته: آپلود با مرورگر گاهی پوشه‌های مخفی را قبول نمی‌کند. اگر نشد، در مخزن «Add file > Create new file» بزن، در کادر اسم بنویس `.github/workflows/android.yml` و محتوای فایل را کپی کن.
2. در مخزن روی تب «Actions» برو. اگر پیام فعال‌سازی داد، «I understand my workflows, enable them» را بزن.
3. در ستون چپ «Build Android APK» را انتخاب کن و «Run workflow» بزن.
4. حدود ۵ تا ۱۰ دقیقه صبر کن تا کنار اجرا تیک سبز بیاید.
5. روی همان اجرا کلیک کن. پایین صفحه در بخش Artifacts فایل `woody-land-apk` است. دانلودش کن و زیپش را باز کن.
6. فایل `app-debug.apk` را به گوشی بفرست و بازش کن. اندروید می‌خواهد «نصب از منابع ناشناس» را برایت فعال کند. اجازه بده و نصب کن.

## نکته‌ها
- APK نسخه‌ی debug است. برای نصب شخصی و دادن به دوستان خوب است، ولی برای گذاشتن در گوگل‌پلی لازم است نسخه‌ی release امضاشده ساخته شود.
- اپ برای بارگذاری Three.js و فونت‌ها اینترنت لازم دارد.
- هر بار `index.html` عوض شد، دوباره Workflow را اجرا کن تا APK جدید ساخته شود.
- شناسه‌ی اپ `com.mrmehni.woodyland` است و در `capacitor.config.json` تغییر می‌کند.
